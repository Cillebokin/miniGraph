# miniGraph 现有功能清单

> 本文根据当前 miniGraph 源码整理，记录已经实现并可从库或示例中使用的功能。示例程序专属能力会单独标注。更新日期：2026-09-23。

## 1. 项目定位与接入

- miniGraph 是基于 Qt Widgets 的二维画布动态库，核心视图使用 `QWidget` 和 `QPainter` 绘制，不依赖 OpenGL。
- 动态库目标名为 `MiniGraph`，通过 `MINIGRAPH_EXPORT` 导出公共符号。
- 提供统一公共头文件 `include/MiniGraph/MiniGraph.h`，可集中引入主要画布 API。
- 当前工程使用 qmake，库依赖 Qt Widgets，代码按 C++11 配置。
- 提供基本示例程序和 Qt Test 测试项目。

## 2. 画布视图与坐标变换

`CanvasView` 是可嵌入 Qt 窗口和布局的画布控件，负责显示画布、管理视图状态和处理基础交互。

- 支持画布世界坐标与控件视口坐标之间的双向转换。
- 世界坐标的 Y 轴朝上，视口坐标的 Y 轴朝下。
- 支持按指定位置缩放，缩放时保持鼠标位置对应的世界坐标不跳动。
- 缩放范围为 `0.000001` 至 `100000`。
- 支持恢复默认视图、将指定世界坐标移到视口中心、适配全部图元和适配选中图元。
- `CanvasTransform` 可独立使用，提供缩放、平移、坐标映射和矩形适配功能。

## 3. 背景、网格、坐标轴和标尺

- 默认背景为黑色。
- 网格默认显示，基础世界坐标间距默认为 `10`，可设置间距或关闭网格。
- 网格会随缩放按十倍级调整间距，适配目标像素间距为约 `10` 至 `100` 像素；当前绘制灰色虚线主网格，主线间距为调整后间距的十倍。
- 坐标轴默认显示，可单独开关。X 轴使用红色半透明线，Y 轴使用绿色半透明线。
- 原点坐标指示器包含 X/Y 方向箭头、方向文字和原点标记，并随世界坐标变换移动。
- 标尺文字可单独开关，默认关闭；显示当前视口范围内的世界坐标刻度，使用黄色文字。
- 网格、坐标轴、标尺的显示状态和网格基础间距可通过属性、方法及对应信号访问。

## 4. 内置图元与文档管理

`CanvasDocument` 负责保存图元数据、图元样式和选择状态。当前内置图元如下：

| 图元 | 几何数据 | 说明 |
|---|---|---|
| 点 | 世界坐标位置 | 使用屏幕像素尺寸绘制 |
| 线段 | 起点、终点 | 可设置颜色和显示线宽 |
| 圆弧 | 圆心、半径、起始角、终止角、方向 | 角度单位为弧度，支持顺时针或逆时针方向 |
| 圆 | 圆心、半径 | 半径必须大于零 |
| 多段线 | 有序顶点列表、开放/闭合标志 | 开放至少 2 个顶点，闭合至少 3 个顶点 |

文档提供以下操作：

- 添加五种内置图元并分配唯一 `ItemId`。
- 按 ID 查询图元类型、样式和几何数据。
- 更新几何数据或样式，删除单个图元，清空全部图元。
- 按世界坐标增量平移一个或多个图元。
- 获取图元 ID、图元数量、全部图元或指定图元集合的包围矩形。
- 保存图元添加顺序，并通过 `Changed()` 和 `SelectionChanged()` 通知观察者。

每个图元可设置描边颜色、选中颜色、描边宽度、点显示尺寸和可见状态。默认图元颜色为白色，默认选中颜色为 RGB `(165, 71, 71)`；默认线宽为 `1`，点尺寸为 `6`。

## 5. 几何算法

- 校验多段线、圆弧和圆的几何数据；多段线顶点必须有限，闭合至少 3 个顶点；圆和圆弧半径必须大于零，圆弧起止角不能相同。
- 计算圆弧扫掠角、方向、指定角度是否落在圆弧上，以及圆弧上的坐标点。
- 计算点、线段、多段线、圆弧和圆的世界坐标包围矩形。
- 按最大误差将圆弧或圆离散为点序列，供绘制和框选算法使用。

## 6. 默认图元绘制与自定义渲染

- 内置 QPainter 渲染器绘制文档中的点、线段、多段线、圆弧和圆；多段线根据开放/闭合状态绘制连接线段。
- 图元按文档添加顺序绘制；不可见图元不显示，选中图元使用其选中颜色。
- 圆弧和圆通过几何离散点绘制。
- 调用方可以实现 `CanvasRenderer`，在背景、内置图元之后或 overlay 阶段绘制自定义 QPainter 内容。
- `CanvasRenderContext` 提供文档只读访问、当前坐标变换、视口尺寸、坐标转换和当前可见世界矩形。
- 自定义渲染器可调用 `RequestUpdate()` 请求画布刷新；每个 `CanvasView` 当前可附加一个自定义渲染器。

当前绘制回调顺序为：自定义背景、内置网格、内置图元、自定义图元绘制、画布 overlay、自定义 overlay。

## 7. 鼠标与键盘交互

| 操作 | 当前行为 |
|---|---|
| 普通鼠标滚轮 | 缩放画布，缩放锚点为鼠标位置 |
| Ctrl + 滚轮 | 缩放画布，缩放锚点为鼠标位置 |
| 触控板像素滚动 | 平移画布 |
| Shift + 滚轮 | 水平平移画布 |
| 按住鼠标中键拖动 | 平移画布 |
| 鼠标右键释放 | 发出上下文菜单请求信号，附带世界坐标和视口坐标 |
| 左键单击空白处 | 不改变当前选择 |
| 左键单击未选图元 | 选择该图元并保留已有选择 |
| 再次单击已选图元 | 切换该图元的选中状态 |
| Shift + 单击图元 | 追加或切换该图元的选中状态 |
| 左向右拖动框选 | 窗口选择，选择框为半透明蓝色填充和实线边框 |
| 右向左拖动框选 | 交叉选择，选择框为半透明绿色填充和虚线边框 |
| 拖动已选图元 | 移动当前选择集合 |
| 拖动单选图元的控制柄 | 编辑图元几何；支持点、线段端点、多段线顶点、圆弧圆心/端点、圆心/半径 |
| Delete 或 Backspace | 删除当前选中的图元 |
| Esc | 取消当前移动或控制柄编辑，并清除选择 |

只有单个图元被选中时显示几何编辑控制柄。普通选中控制柄为蓝色，正在拖动的控制柄为橙色。

Shift 按下和释放会更新 `orthogonalMode` 状态并发出信号。当前源码只提供此状态通知，尚未将正交约束应用到图元几何操作。

## 8. 捕捉

- 支持单独启用或关闭捕捉预览、网格捕捉和几何捕捉。
- 几何捕捉对象包括点、线段端点、多段线顶点、圆弧圆心与端点、圆心。
- 捕捉仅考虑可见图元；几何捕捉点优先于网格捕捉点。
- 捕捉结果包含捕捉类型、图元 ID 和世界坐标，并通过 `SnapChanged()` 通知调用方。
- 网格捕捉使用随当前缩放调整后的网格间距。
- 捕捉预览显示黄色标记：网格捕捉使用方形标记，几何捕捉使用圆形标记。

## 9. 对外属性与信号

`CanvasView` 公开 Qt 属性和信号，可用于 Qt 信号槽、属性绑定及调用层状态同步。当前可观察状态包括：

- 网格显示状态和基础间距。
- 缩放比例。
- 坐标轴和标尺显示状态。
- Shift 正交状态。
- 捕捉预览、网格捕捉和几何捕捉开关。
- 当前捕捉结果、鼠标世界坐标。
- 右键上下文菜单请求和交互取消通知。

## 10. 示例程序提供的能力

以下是 `examples/basic` 演示程序的界面功能，不属于 `CanvasView` 自动提供的工具：

- 工具栏切换网格、坐标轴、标尺、捕捉及自定义渲染层。
- 重置画布、适配全部图元、适配选中图元、将原点居中。
- 通过参数对话框创建点、线段、多段线、圆弧和圆，并插入 `CanvasDocument`；多段线参数为逐行 `x,y` 顶点文本与闭合开关。
- 通过参数对话框编辑单个选中图元的几何数据和样式，多段线支持顶点列表与闭合状态编辑。
- 自定义渲染器示例展示背景、几何和 overlay 的绘制及刷新请求。

## 11. 当前功能范围说明

- 文档内置并可自动参与默认绘制、选择、编辑和捕捉的图元类型为点、线段、多段线、圆弧和圆。
- 图元参数化创建由调用层完成；示例中的对话框用于演示调用 `CanvasDocument` API，核心库没有内置逐点点击创建工具。
- 自定义渲染器负责绘制自定义视觉内容；自定义绘制内容不会自动加入 `CanvasDocument`，也不会自动参与内置命中测试、选择、编辑或捕捉。
- 当前渲染器接口支持一个附加渲染器；需要组合多类绘制内容时，可由调用方在一个渲染器中组织。
