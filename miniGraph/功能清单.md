# miniGraph 现有功能清单

> 本文根据当前 miniGraph 源码整理，记录已经实现并可从库或示例中使用的功能。示例程序专属能力会单独标注。更新日期：2026-10-09。

## 1. 项目定位与接入

- miniGraph 是基于 Qt Widgets 的二维画布动态库，核心视图使用 `QWidget` 和 `QPainter` 绘制，不依赖 OpenGL。
- 动态库目标名为 `MiniGraph`，通过 `MINIGRAPH_EXPORT` 导出公共符号。
- 提供统一公共头文件 `include/MiniGraph/MiniGraph.h`，可集中引入主要画布 API。
- 当前工程使用 qmake，库依赖 Qt Widgets，代码按 C++11 配置。
- 提供基本示例程序和 Qt Test 测试项目。

## 2. 画布视图与坐标变换

`CanvasView` 是可嵌入 Qt 窗口和布局的画布控件，负责显示画布、管理视图状态和处理基础交互。

- 支持画布世界坐标与控件视口坐标之间的双向转换。
- 世界坐标的 Y 轴朝上，视口坐标的 Y 轴朝下。
- 支持按指定位置缩放，缩放时保持鼠标位置对应的世界坐标不跳动。
- 缩放范围为 `0.000001` 至 `100000`。
- 支持恢复默认视图、将指定世界坐标移到视口中心、适配全部图元和适配选中图元。
- `CanvasTransform` 可独立使用，提供缩放、平移、坐标映射和矩形适配功能。

## 3. 背景、网格、坐标轴和标尺

- 默认背景为黑色。
- 网格默认显示，基础世界坐标间距默认为 `10`，可设置间距或关闭网格。
- 网格会随缩放按十倍级调整间距，适配目标像素间距为约 `10` 至 `100` 像素；当前绘制灰色虚线主网格，主线间距为调整后间距的十倍。
- 坐标轴默认显示，可单独开关。X 轴使用红色半透明线，Y 轴使用绿色半透明线。
- 原点坐标指示器包含 X/Y 方向箭头、方向文字和原点标记，并随世界坐标变换移动。
- 标尺文字可单独开关，默认关闭；显示当前视口范围内的世界坐标刻度，使用黄色文字。
- 网格、坐标轴、标尺的显示状态和网格基础间距可通过属性、方法及对应信号访问。

## 4. 内置图元与文档管理

`CanvasDocument` 负责保存图元数据、图元样式和选择状态。当前内置图元如下：

| 图元 | 几何数据 | 说明 |
|---|---|---|
| 点 | 世界坐标位置 | 使用屏幕像素尺寸绘制 |
| 线段 | 起点、终点 | 可设置颜色和显示线宽 |
| 圆弧 | 圆心、半径、起始角、终止角、方向 | 角度单位为弧度，支持顺时针或逆时针方向 |
| 圆 | 圆心、半径 | 半径必须大于零 |
| 椭圆 | 圆心、长轴向量、短长轴比例 | 支持整椭圆和椭圆弧 |
| 多段线 | 有序顶点列表、开放/闭合标志 | 开放至少 2 个顶点，闭合至少 3 个顶点 |
| 样条曲线 | 次数、控制点、节点向量、权重及闭合状态 | 支持 NURBS 数据与曲线离散绘制 |
| 组容器 | 有序子图元集合 | 子图元由组独立持有副本，可嵌套 |

文档提供以下操作：

- 通过通用 `AddEntity()` 添加八种内置图元并分配唯一 `ItemId`；类型化便捷创建/几何接口目前覆盖点、线段、圆弧、圆和多段线。
- 按 ID 查询图元类型、样式和几何数据；椭圆、样条曲线和组容器通过通用实体接口访问。
- 更新受支持的几何数据或样式，替换、删除单个图元，清空全部图元。
- 按世界坐标增量平移一个或多个图元。
- 获取图元 ID、图元数量、全部图元或指定图元集合的包围矩形。
- 支持单选、追加/切换选择、窗口框选和交叉框选，并通过 `SelectionChanged()` 通知观察者。
- 保存图元添加顺序，并通过 `Changed()` 和 `SelectionChanged()` 通知观察者。

每个图元可设置描边颜色、选中颜色、描边宽度、点显示尺寸和可见状态。默认图元颜色为白色，默认选中颜色为 RGB `(165, 71, 71)`；默认线宽为 `1`，点尺寸为 `6`。

## 5. 几何算法

- 校验点、线段、圆弧、圆、椭圆、多段线、样条曲线及组容器数据，并计算安全包围盒。
- 多段线顶点必须有限，闭合至少 3 个顶点；圆和圆弧半径必须大于零，圆弧起止角不能相同；样条曲线校验次数、节点向量和权重。
- 计算圆弧扫掠角、方向、指定角度是否落在圆弧上，以及圆弧上的坐标点。
- 计算各类图元及嵌套组的世界坐标包围矩形。
- 按最大误差离散圆弧、圆、椭圆和样条曲线，供绘制、命中检测和选择算法复用。

## 6. 默认图元绘制与自定义渲染

- 内置 QPainter 渲染器绘制八种实体；多段线根据开放/闭合状态绘制连接线段，组容器递归绘制子图元。
- 图元按文档添加顺序绘制；不可见图元不显示，选中图元使用其选中颜色。
- 圆弧、圆、椭圆和样条曲线按屏幕误差控制进行离散绘制。
- 调用方可以实现 `CanvasRenderer`，在背景、内置图元之后或 overlay 阶段绘制自定义 QPainter 内容。
- `CanvasRenderContext` 提供文档只读访问、当前坐标变换、视口尺寸、坐标转换和当前可见世界矩形。
- 渲染框架会隔离各自定义回调的 QPainter 状态；背景、几何和 overlay 回调均不会把变换、裁剪或画笔状态泄漏到后续内置绘制。
- 自定义渲染器可调用 `RequestUpdate()` 请求画布刷新；每个 `CanvasView` 当前可附加一个自定义渲染器。
- 三张离屏 QImage 图层会在尺寸或设备像素比变化时重建，其余重绘复用已有缓冲区。

当前绘制顺序为：自定义背景、内置网格、CanvasGlobalData 前置数据、每个实体的 CanvasData 与实体几何、自定义图元绘制、CanvasGlobalData 后置数据、画布 overlay、自定义 overlay。

### CanvasData 与 CanvasGlobalData

- `CanvasData` 附着在单个实体上，支持 `Clone()`、`CalculateToQStringList()` 和 `Update()`；绘制指令包含 Pen、Brush、Font、Point、Line、Arc、Ellipse、Polyline、Polygon、Rect、Cubic、Quad、Text 和 Image。
- Brush 使用 Qt `BrushStyle`，包含水平线、竖直线、交叉线等 hatch 填充样式。
- `CanvasGlobalData` 附着在文档上，分别提供前置和后置绘制指令。
- `CanvasView`、关联的 `CanvasDocument` 及其附加数据不提供并发保护，应在 GUI 线程访问和修改；扩展绘制指令在绘制期间同步调用，不应阻塞。
- 对已附着的数据对象进行原地修改后，先完成一组修改，再调用 `CanvasDocument::NotifyItemCanvasDataChanged()` 或 `NotifyCanvasGlobalDataChanged()` 通知文档刷新视图。
- 单个 `CanvasData` 实例一次只能绑定一个实体；实体解绑、替换或销毁时会通过 `Update(nullptr)` 清除绑定。`TrySetCanvasData()` 会报告绑定失败，旧的 `SetCanvasData()` 在数据已绑定到其他实体时保持原状。
- 克隆实体时会调用 `CanvasData::Clone()`，派生类必须提供独立且隔离可变状态的副本；`CanvasGlobalData::Clone()` 不会自动调用，由调用方在需要独立文档状态时显式使用。
- [Canvas 扩展数据线程、通知与克隆约定及示例](Canvas扩展数据使用契约.md)
- 当前 miniGraph 尚未提供实体、CanvasData 或 CanvasGlobalData 的序列化接口。

## 7. 鼠标与键盘交互

| 操作 | 当前行为 |
|---|---|
| 普通鼠标滚轮 | 缩放画布，缩放锚点为鼠标位置 |
| Ctrl + 滚轮 | 缩放画布，缩放锚点为鼠标位置 |
| 触控板像素滚动 | 平移画布 |
| Shift + 滚轮 | 水平平移画布 |
| 按住鼠标中键拖动 | 平移画布 |
| 鼠标右键释放 | 发出上下文菜单请求信号，附带世界坐标和视口坐标 |
| 左键单击空白处 | 不改变当前选择 |
| 左键单击未选图元 | 选择该图元并保留已有选择 |
| 再次单击已选图元 | 切换该图元的选中状态 |
| Shift + 单击图元 | 追加或切换该图元的选中状态 |
| 左向右拖动框选 | 窗口选择，选择框为半透明蓝色填充和实线边框 |
| 右向左拖动框选 | 交叉选择，选择框为半透明绿色填充和虚线边框 |
| 拖动已选图元 | 移动当前选择集合 |
| 拖动单选图元的控制柄 | 编辑几何；支持点、线段端点、圆弧圆心/端点、圆心/半径、椭圆轴/弧端点、样条控制点、多段线顶点；组支持通过参考点整体移动 |
| Delete 或 Backspace | 删除当前选中的图元 |
| Esc | 取消当前移动或控制柄编辑，并清除选择 |

只有单个图元被选中时显示几何编辑控制柄。普通选中控制柄为蓝色，正在拖动的控制柄为橙色。

Shift 按下和释放会更新 `orthogonalMode` 状态并发出信号。当前源码只提供此状态通知，尚未将正交约束应用到图元几何操作。

### CanvasAction

- 调用层可安装一个默认 Action，以替换画布内置编辑交互；也可临时安装当前 Action，临时 Action 优先并独占编辑鼠标/键盘输入。
- Action 可接收鼠标按下、移动、释放、双击及键盘按下/释放事件，并可在 overlay 阶段绘制临时预览。
- `RequestUpdate()` 请求重绘；临时 Action 可调用 `Finish()` 正常结束，或由 Esc 取消。Esc 取消临时 Action 时保留当前选择。
- Action 安装到 `CanvasView` 后由画布接管对象所有权；临时 Action 结束后删除并恢复默认 Action 或内置交互。
- 中键拖拽平移、滚轮缩放仍由 `CanvasView` 全局处理，不被 Action 截获。
- 进入 `PreviewNavigation` 会取消临时 Action，并暂停默认 Action 的输入与预览；切回编辑模式后恢复默认 Action。
- 当前不支持嵌套 Action 栈、命令行输入、相对零点或 Action 序列化。

## 8. 捕捉

- 支持单独启用或关闭捕捉预览、网格捕捉和几何捕捉。
- 几何捕捉对象包括点、线段端点、多段线顶点、圆弧圆心与端点、圆心、椭圆中心/轴点/弧端点和样条曲线端点；组递归检查子图元。
- 捕捉仅考虑可见图元；几何捕捉点优先于网格捕捉点。
- 捕捉结果包含捕捉类型、图元 ID 和世界坐标，并通过 `SnapChanged()` 通知调用方。
- 网格捕捉使用随当前缩放调整后的网格间距。
- 捕捉预览显示黄色标记：网格捕捉使用方形标记，几何捕捉使用圆形标记。

## 9. 对外属性与信号

`CanvasView` 公开 Qt 属性和信号，可用于 Qt 信号槽、属性绑定及调用层状态同步。当前可观察状态包括：

- 网格显示状态和基础间距。
- 缩放比例。
- 坐标轴和标尺显示状态。
- Shift 正交状态。
- 捕捉预览、网格捕捉和几何捕捉开关。
- 当前捕捉结果、鼠标世界坐标。
- 右键上下文菜单请求和交互取消通知。

## 10. 示例程序提供的能力

以下是 `examples/basic` 演示程序的界面功能，不属于 `CanvasView` 自动提供的工具：

- 工具栏切换网格、坐标轴、标尺、捕捉及自定义渲染层。
- 重置画布、适配全部图元、适配选中图元、将原点居中。
- 通过参数对话框创建点、线段、多段线、圆弧和圆，并插入 `CanvasDocument`；多段线参数为逐行 `x,y` 顶点文本与闭合开关。
- 通过参数对话框编辑点、线段、多段线、圆弧和圆的几何数据和样式；Ellipse、Spline、GroupContainer 目前没有对应的基础示例对话框。
- 自定义渲染器示例展示背景、几何和 overlay 的绘制及刷新请求。
- `Place point` 示例演示通过临时 `CanvasAction` 在鼠标位置（有有效捕捉结果时使用捕捉坐标）放置一个点，然后自动结束并恢复内置交互。
- `Draw line` 示例演示双击点式直线创建：首点确定后显示临时预览，次点插入线段；捕捉坐标可用，按 `Esc` 取消且不插入图元。
- `Draw circle` 示例演示两点式圆创建：首点确定圆心，移动鼠标预览半径，次点确定半径并插入圆；捕捉坐标可用，按 `Esc` 取消且不插入图元；零半径或非法半径会被拒绝，Action 保持活动以便重新指定。
- 基础示例展示 `CanvasData` / `CanvasGlobalData` 的绘制、实体数据克隆、原地修改及显式刷新通知；全局数据克隆由调用层显式控制。

## 11. 当前功能范围说明

- 文档内置并可自动参与默认绘制、选择、编辑和捕捉的类型为点、线段、圆弧、圆、椭圆、多段线、样条曲线和组容器。
- 图元参数化创建由调用层完成；示例中的对话框只覆盖点、线段、多段线、圆弧和圆，核心库没有内置逐点点击创建工具。
- 自定义渲染器负责绘制自定义视觉内容；自定义绘制内容不会自动加入 `CanvasDocument`，也不会自动参与内置命中测试、选择、编辑或捕捉。
- 当前渲染器接口支持一个附加渲染器；需要组合多类绘制内容时，可由调用方在一个渲染器中组织。
- `CanvasView` 仍对完整文档进行重绘，绘制、命中检测和捕捉主要采用线性图元遍历；目前没有 CADLab 的 RTree 空间索引，也尚未建立大规模图纸性能基准。
- CanvasData 的图像指令当前在绘制时读取图片；包含频繁重绘或大量图元的工作负载应单独做性能测量。
- `CanvasAction` 当前提供事件分发及 overlay 扩展入口；点、直线和圆的交互创建由基础示例演示，其他图元的交互工具仍需由调用层自行实现。
